# Teach Easy

小学数学一年级上册互动教具原型。

## 当前内容

- `index.html`、`styles.css`、`app.js`：Vercel 默认部署入口，直接展示整本教材汇总版互动教具。
- `汇总测试/`：整本教材汇总版互动教具入口，包含章节下拉选择和 A/B 风格切换。
- `测试/`：早期单节互动案例和教材章节梳理文档。

## 本地预览

在项目根目录运行：

```bash
python3 -m http.server 8781 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:8781/
```
